# MAL3018 Computing Project
### *IsyaratKu* - Sign Language Recognition System with MediaPipe
Static Bahasa Isyarat Malaysia (BIM) gesture recognition using MediaPipe — a Final Year Project

##
### About
IsyaratKu is a computer vision system that recognises static BIM (Malaysian Sign Language) gestures — fingerspelling and a core set of everyday vocabulary — using MediaPipe hand-landmark extraction paired with a machine learning classifier. Recognised gestures are composed sequentially into words or short phrases, deployed as an Android application with a live camera demo.

BIM has almost no computational or assistive-technology resources compared to ASL, despite serving a real community of Deaf Malaysians. This project is a first step toward accessible, camera-based BIM recognition tools.

<sub>*This is a student prototype, not a clinically validated or comprehensive communication tool*</sub>
